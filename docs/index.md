## Кому це

**Хочете написати свій клієнт.** Почніть зі
[«Свій клієнт за 15 хвилин»](/guide/quickstart-client) — наскрізний шлях від
підключення до звуку. Потім [«Свій адмінський клієнт»](/guide/admin-client),
якщо потрібне керування ефіром. Далі [Довідник REST](/reference/rest) і
[Події Socket.io](/reference/socket-events).

**Хочете підняти власне радіо.** Дивіться
[Запуск власного сервера](/guide/self-hosting): мінімальна конфігурація не
потребує ні хмарного сховища, ні бази даних.

**Читаєте код.** Розділ «Протокол» пояснює рішення, які з коду не видно:
[токени і доступ](/protocol/tokens),
[режими програвання](/protocol/playback-modes),
[формат повідомлень](/protocol/messages).

## Як підтримується довідник

Таблиці ендпоінтів, подій і привілеїв **генеруються з коду сервера** скриптом
`docs/scripts/extract-api.mjs`, а не пишуться руками. Він читає декларативні
охоронці роутів і назви сокетних подій просто з вихідних файлів.

```bash
cd docs && npm run extract
```

Той самий скрипт із прапорцем `--check` варто запускати перед комітом: він
падає, якщо згенероване розійшлося із закоміченим, і одразу показує, які
ендпоінти чи події лишилися невідображеними.
